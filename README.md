# Mollis and Sisu

An interactive autumn storybook: a branching woodland tale with a hidden birthday surprise for Lera.

Plain static site, no build step. Deploy the repository root as-is (Vercel: Framework Preset "Other", no build command, output directory = root).

- `index.html`: the whole app
- `img/`: scene illustrations
- `ui/`: hand-drawn buttons, icons and paper texture
- `audio/`: background loop and the birthday song
- `video/`: the little film shown at the end
